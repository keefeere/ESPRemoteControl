# Origins and third-party acknowledgements

## Original project

This repository is based on
[ESPRemoteControl](https://github.com/KoStard/ESPRemoteControl) by
[Ruben Kostandyan](https://github.com/KoStard). The original project provided
the initial SwiftUI application and ESP32-S3 BLE-to-USB HID bridge on which
this project was built.

The original repository's README describes the project as MIT-licensed and
refers to a `LICENSE` file. No such file is present in the original repository
or in the imported Git history as of September 19, 2026. This notice records
the project's provenance but does not attempt to supply or reinterpret the
missing license grant.

## NimBLE-Arduino

The ESP32 firmware depends on
[NimBLE-Arduino](https://github.com/h2zero/NimBLE-Arduino), maintained by Ryan
Powell and the esp-nimble-cpp and NimBLE-Arduino contributors. NimBLE-Arduino
is distributed under the Apache License 2.0 and includes its own
[license](https://github.com/h2zero/NimBLE-Arduino/blob/master/LICENSE) and
[NOTICE](https://github.com/h2zero/NimBLE-Arduino/blob/master/NOTICE) files.
The library is installed separately and its source is not vendored in this
repository.
